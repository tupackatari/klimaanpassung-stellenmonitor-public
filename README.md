# Klimaanpassung · Stellenmonitor

Öffentliche, bereinigte Website zu Stellenausschreibungen im öffentlichen Sektor. Dieses Repository enthält ausschließlich die veröffentlichte Ansicht. Volltexte, historische Textfassungen und offene Prüffälle werden in einem separaten privaten Archiv aufbewahrt. Die redaktionelle Anmeldung liest private Daten ausschließlich über die authentifizierte GitHub-API in den Arbeitsspeicher des angemeldeten Browsers.
